# 后台和打包

后台地址：`http://127.0.0.1:8765/admin`

页面上可以建游戏、商品、渠道参数和广告位，并查看订单。单机游戏不要填存档。激励完成单只对网游打开。

渠道 appId、包名和适配器类要重新出包才生效。广告代码位在 SDK 初始化时向发行服务拉取；单机配置没有 `serverBaseUrl` 时，用打包写进 `aggregator.json` 的映射。

```sh
python3 aggregator/packager/pack.py \
  --app-id g_xxx \
  --channel test \
  --from-server http://127.0.0.1:8765 \
  --offline \
  --out assets/aggregator.json
```

`--offline` 会清掉服务器地址，即使同时写了 `--server`。`oppo`、`vivo`、`huawei`、`xiaomi` 已有适配器。没有适配器的渠道会直接失败，不会生成空壳配置。

打包机另外负责放入该渠道的官方 aar、Manifest 和签名。这个工具只生成聚合配置。
