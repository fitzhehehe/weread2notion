# 新增渠道适配器

实现 `com.aggregator.sdk.ChannelAdapter`，类要有无参构造。登录方法里调用该渠道 SDK，把渠道用户号填进 `LoginResult`。不要在登录里请求发行服务。

角色上报调用渠道要求的创角、进服、升级接口。支付只拉起渠道收银台，发货不写在适配器里。广告方法收到的是渠道代码位，不是游戏里的聚合广告位。

OPPO、vivo、华为、小米已经有适配器，类名见 `channels/README.md`。打包示例：

```sh
python3 aggregator/packager/pack.py \
  --app-id g_xxx \
  --channel oppo \
  --offline \
  --param appSecret=从OPPO后台复制 \
  --param notifyUrl=https://pay.example/oppo \
  --out assets/aggregator.json
```

新渠道才需要自己写类并用 `--adapter-class`。

适配器的 `channelCode()` 必须和配置里的 `channelCode` 一致，否则初始化失败。
