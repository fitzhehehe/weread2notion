这一页是进度和分工。游戏接法看 [游戏接入](游戏接入.md)，支付报文看 [游戏服与支付](游戏服与支付.md)，后台命令看 [后台和打包](后台和打包.md)，四家渠道看 [channels/README.md](../channels/README.md)。

## 背景

自家发行要把同一款游戏上到 OPPO、vivo、华为、小米。游戏只接一次。登录账号是渠道的，聚合 SDK 把这一次调用交给当前渠道包里的渠道 SDK。单机不部署发行服务器也可以登录，进度留在手机上。

发行服务器只在要认支付账、改广告位映射时使用。它不保存游戏存档。客户端支付回调不能发货。

## 已定范围

- 游戏工程只提供 Unity 和 Cocos Creator 的调用。产出物是 Android 渠道包。
- 第一批渠道是 OPPO、vivo、华为应用市场、小米游戏联运。
- 广告先做广告位。游戏只持有聚合广告位 ID。
- 不做鸿蒙、iOS、小游戏、买量统计、自研广告竞价、存档同步。

## 现在需要你做的

先做下面三步。做完把 `aggregator/vendor/` 里的文件留在本机，并说明你选的第一家渠道。密钥不要贴到聊天记录里，放在本机文件即可。

### 1. 选定第一家真机渠道

四家一起上真机验不完。回复时只写一个编码：`oppo`、`vivo`、`huawei` 或 `xiaomi`。

没有偏好时用 `vivo`。它的登录、支付和激励视频都已经写进适配器。

### 2. 下载官方 SDK

只下载你选定的那一家，外加它的广告包（如果有）。解压后的 aar、jar 放进 `aggregator/vendor/<渠道编码>/`。

目录例：

```text
aggregator/vendor/vivo/vivounionsdk.aar
aggregator/vendor/vivo/vivo-ad.aar
```

各开放平台：

1. OPPO：登录 https://open.oppomobile.com/ ，进入已创建的游戏，在联运或 SDK 下载里取游戏中心联运 SDK。广告联盟是另一个包，这一步可以不下。
2. vivo：登录 https://dev.vivo.com.cn/ ，联运 SDK 说明在 https://dev.vivo.com.cn/documentCenter/doc/8 ，激励视频说明在 https://dev.vivo.com.cn/documentCenter/doc/730 。两个包都下载。
3. 华为：登录 AppGallery Connect，按 https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/appgallerykit-app-sdk-0000001667017048 取 Android 联运和游戏服务相关 SDK。不要下鸿蒙 NEXT 的包。
4. 小米：登录 https://dev.mi.com/ ，按 https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1377 下载游戏联运 SDK（`miLogin` 那一套）。不要下联运 2.0 的统一包。

下载页如果要求先创建应用，就用测试包名先建一个草稿应用，再下 SDK。

### 3. 抄渠道参数

在同一家后台的应用详情里复制参数，写到 `aggregator/vendor/<渠道编码>/params.txt`。不要把支付私钥写进游戏工程。

每家最少这些行：

```text
channelAppId=
appKey=
appSecret=
packageName=
notifyUrl=
```

没有的行留空，不要删行。vivo 的支付签名在服务端算，`appSecret` 填支付密钥。华为如果只有客户端参数，`appSecret` 可以空着。`notifyUrl` 还没有公网地址时写 `http://127.0.0.1:8765/v1/channels/<渠道编码>/pay-notify`，真机支付前再改成手机访问得到的地址。

准备一台对应品牌的手机，打开开发者选项里的 USB 调试。渠道后台如果有沙箱账号，记下账号所在的后台页面，账号密码放在你自己的密码记录里，不要写进 `params.txt`。

## 你交来之后会做的
