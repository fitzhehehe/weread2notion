## 背景

自家发行要把同一款游戏上到 OPPO、vivo、华为、小米。游戏只接一次。登录账号是渠道的，聚合 SDK 把这一次调用交给当前渠道包里的渠道 SDK。单机不部署发行服务器也可以登录，进度留在手机上。

发行服务器只在要认支付账、改广告位映射时使用。它不保存游戏存档。客户端支付回调不能发货。

## 已定范围

- 游戏工程只提供 Unity 和 Cocos Creator 的调用。产出物是 Android 渠道包。
- 第一批渠道是 OPPO、vivo、华为应用市场、小米游戏联运。
- 广告先做广告位。游戏只持有聚合广告位 ID。
- 不做鸿蒙、iOS、小游戏、买量统计、自研广告竞价、存档同步。

## 现在需要你做的

第一家渠道定为 vivo。联运 SDK 4.9.3.1 已从你给的文档页下载并核对。广告包要登录后才能下。

### 1. 下载 vivo 广告联盟 SDK

1. 用 vivo 开发者账号打开 https://dev.vivo.com.cn/documentCenter/doc/723 。
2. 点击文中的下载地址，它会进到 https://adnet.vivo.com.cn/admin/access/sdk/1 。未登录时先登录。
3. 下载当前广告联盟 SDK 压缩包。
4. 解压后把 aar 放到 `aggregator/vendor/vivo/`，文件名保持压缩包里的原名。
5. 回复一句「广告包已放好」，并写上 aar 文件名。不要把包上传到公开仓库。

### 2. 抄 vivo 应用参数

在 vivo 开放平台已创建的游戏里复制参数，写到 `aggregator/vendor/vivo/params.txt`：

```text
channelAppId=
appKey=
cpId=
packageName=
notifyUrl=
```

`appKey` 是支付密钥，服务端用它算签名，不要放进游戏包。`channelAppId` 是 vivo 的 appId。`notifyUrl` 先写 `http://127.0.0.1:8765/v1/channels/vivo/pay-notify`，真机支付前改成手机能访问的地址。没有的行留空。

沙箱账号和密码不要写进这个文件，也不要贴到对话里。

### 3. 准备一台 vivo 手机

打开开发者选项里的 USB 调试。用数据线连到跑这个工程的电脑。这一步先不用操作游戏，等适配器用广告包编译通过后再装包。

## 你交来之后会做的

1. 用广告联盟 aar 编译 vivo 激励视频适配器，方法名对不上就改。
2. 生成 vivo 渠道的 `aggregator.json`。
3. 在你的 vivo 手机上看登录能否返回 openId。
4. 有沙箱支付时再走一笔。客户端回调仍然不能发货。vivo 的支付通知按官方表单验签，成功时回复 `success`。
